AKG Knowledge Graph Explorer
============================

AKG is a desktop application for exploring RDF knowledge graphs produced by
the Autism Knowledge Graph (AKG) pipeline.  The service layer in
:mod:`kg_services` is responsible for all domain logic: graph loading, label
resolution, UUID translation, binning metadata, SPARQL execution, and article
metadata lookup.
